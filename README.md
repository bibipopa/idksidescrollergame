# RIFT//RAID: Ashen Hundred

Браузерный кооперативный soulslike-рогалик для 1–4 игроков. Комнаты синхронизируются через Socket.IO, а бой, босс, стадии и перки рассчитываются на сервере.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Для Render используются:

```text
Build Command: npm install
Start Command: npm start
Health Check Path: /health
```

## Управление

- `A` / `D` — движение
- `W` — прыжок
- `J` — лёгкая атака
- `H` — парирование
- `K` — тяжёлая атака
- `L` — перекат

## Игровой цикл

- Забег можно начать одному или группой до четырёх игроков.
- У каждого персонажа изначально 3 здоровья и нет автоматических возрождений внутри стадии.
- Если хотя бы один участник побеждает босса, вся команда возвращается на следующей стадии.
- После каждой победы каждый игрок выбирает один из трёх случайных перков.
- Сложность и здоровье босса растут до 100-й стадии.
- Каждые 10 стадий меняются оформление, расположение платформ и опасности арены.
- У босса 13 видов атак. Новые приёмы постепенно открываются на стадиях 8, 15, 25, 35, 45, 60 и 75.
- Валюта, разблокированные классы и облики оружия сохраняются в `localStorage` текущего браузера.

## Арены

В забеге десять арен: от безопасных Пепельных врат до Трона Пустоты. С каждым новым десятком платформы становятся уже, а на поле постепенно появляются огненные выбросы, руны, падающие удары, клинки и грозовые колонны. Все предупреждения и попадания синхронизируются сервером.

## Атаки босса

Помимо обычного взмаха, кругового удара, падения на землю, залпа, волны и рывка босс получает двойной взмах, падение снарядов сверху, телепортационный удар, круговой залп, луч, двойное землетрясение и метки под игроками.

## Классы

- **Мечник** — доступен сразу, сбалансирован.
- **Тяжёлый мечник** — открывается за 600 пепла, медленный и мощный.
- **Вор** — открывается за 900 пепла, быстрый и экономный по выносливости.

Папку `node_modules` загружать на GitHub не нужно.
