# RIFT//RAID: Ashen Hundred

Браузерный кооперативный soulslike-рогалик для 1–4 игроков. Комнаты синхронизируются через Socket.IO, а бой, босс, стадии и перки рассчитываются на сервере.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Для Render используются:

```text
Build Command: npm install
Start Command: npm start
Health Check Path: /health
```

## Управление

- `A` / `D` — движение
- `W` — прыжок
- `J` — лёгкая атака
- `H` — парирование
- `K` — тяжёлая атака
- `L` — перекат
- `U` — активировать «Клятву отряда», когда командная шкала заполнена

## Игровой цикл

- Забег можно начать одному или группой до четырёх игроков.
- У каждого персонажа изначально 3 здоровья и нет автоматических возрождений внутри стадии.
- Между стадиями выжившие сохраняют оставшееся здоровье: полного лечения после победы нет.
- Если хотя бы один участник побеждает босса, павшие союзники возвращаются на следующей стадии ровно с 1 HP.
- После каждой победы каждый игрок выбирает один из трёх случайных перков. В игре 70 перков, включая 36 классовых карт.
- После выбора перков команда голосует за один из трёх маршрутов. Маршрут меняет награду, запас здоровья и скорость босса, опасности арены или условия команды.
- Первая Комната тихого света появляется среди маршрутов примерно после 3–5 побед, следующие — через 4–6 стадий. При выборе живые игроки восстанавливают до 2 HP, павшие всё равно возвращаются с 1 HP, а награда следующей стадии уменьшается.
- В начале забега выбирается случайный модификатор, меняющий правила всего прохождения.
- Забег состоит из 50 стадий: на каждого из десяти боссов приходится по пять боёв.
- Сложность пересчитана по прежней ускоренной кривой, поэтому финальный босс на 50-й стадии примерно соответствует прежней 100-й стадии. Маршруты, размер команды и модификатор дополнительно меняют его запас HP.
- Каждые 10 стадий урон босса повышается на 1: от 1 HP на стадиях 1–10 до 5 HP на стадиях 41–50.
- Новый босс и новая арена появляются каждые 5 стадий.
- У каждого босса собственные наборы ближних и дальних атак, темп движения и три фазы. Вторая фаза начинается при 50% HP, третья — при 20%.
- Боссы выбирают цель с учётом угрозы, предсказывают движение, меняют дистанцию, ускоряются, делают рывки и перепрыгивают разломы.
- Успешные парирования заполняют общую шкалу. Согласованные парирования дают больше энергии, а заполненная «Клятва отряда» восстанавливает выносливость, защищает команду и оглушает босса.
- В игре 18 видов оружия — по три на класс. Первое доступно на 1-м уровне класса, второе открывается на 5-м, третье — на 12-м.
- Опыт начисляется отдельно выбранному классу за пройденных боссов и нанесённый урон. Максимальный уровень класса — 50.
- В арсенале есть Пепельные ковчеги за 20 000 пепла. Ковчег открывается 10 минут, одновременно могут открываться до трёх.
- В ковчегах находится 216 постоянных классовых навыков: 36 для каждого класса. Повторов нет, а в бой можно взять до трёх навыков выбранного класса.
- Есть ежедневные задания, достижения, редактор цвета брони и следа движения.
- В верхней панели можно выбрать маленький, обычный или крупный масштаб текста и остальных элементов интерфейса. Выбор сохраняется на устройстве.
- Валюта, уровни классов, разблокированные классы, оружие, облики, навыки, достижения и таймеры ковчегов сохраняются в `localStorage` текущего браузера.
- Игровое поле отрисовывается в низком разрешении с резким пиксельным масштабированием; персонажи, босс, оружие, платформы и снаряды используют простые пиксельные формы.

## Арены

В забеге десять арен: от безопасных Пепельных врат до Трона Пустоты. С каждым новым десятком платформы становятся уже, крайние пропасти расширяются, а начиная с 21-й стадии внутри пола появляются настоящие разломы. На поле постепенно добавляются огненные выбросы, руны, падающие удары, клинки и грозовые колонны. Падение в пропасть снимает 1 HP и возвращает персонажа в безопасную точку. Все предупреждения и попадания синхронизируются сервером.

## Боссы и атаки

Десять боссов используют разные сочетания ближних серий, рывков, прыжков, волн, залпов, лучей, меток, телепортаций и атак по зонам. На новых фазах открываются дополнительные приёмы, а предупреждения становятся короче. У каждого босса своё оформление, цвет эффектов и ритм фоновой темы.

## Классы

- **Мечник** — доступен сразу, сбалансирован.
- **Тяжёлый мечник** — 1800 пепла, медленный и мощный.
- **Вор** — 2600 пепла, быстрый и экономный по выносливости.
- **Копейщик** — 3800 пепла, атакует с большой дистанции и усиливает выпады.
- **Берсерк** — 5200 пепла, развивает тяжёлые удары, серии и бой на низком здоровье.
- **Пепельный маг** — 7500 пепла, использует дальние снаряды и веерные заклинания.

У каждого класса есть шесть собственных перков. В каждой тройке карт гарантирован хотя бы один классовый вариант; перки других классов выпасть не могут. Классовые карты меняют не только характеристики, но и механику атак: добавляют режущие волны, землетрясения, серии кинжалов, усиленные выпады, ярость и дополнительные магические снаряды.

Уровень и опыт считаются отдельно для каждого класса. Три его боевых стиля оружия открываются на уровнях 1, 5 и 12. Смена оружия меняет скорость, дальность, урон и особые свойства атак, но не расходует пепел.

Прогресс хранится только в браузере устройства: системы аккаунтов и облачной синхронизации в этой версии нет.

Папку `node_modules` загружать на GitHub не нужно.
